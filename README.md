# Landing page para Servicio Express Saldo PayPal Nicaragua

Sitio estatico listo para abrir en navegador o subir a un hosting.

## Cambios rapidos

- Nombre del negocio: cambia `Servicio Express Saldo PayPal Nicaragua` en `index.html` y `script.js`.
- WhatsApp: cambia `whatsappNumber` en `script.js`. Usa formato internacional sin `+`.
- Facebook: cambia `facebookUrl` en `script.js`.
- Comisiones, metodos de retiro y textos comerciales: editalos directamente en `index.html`.
- Logo y banner: estan en `assets/logo-saldo-paypal.png` y `assets/banner-saldo-paypal.png`.

## Archivos

- `index.html`: contenido de la pagina.
- `styles.css`: diseno visual y version movil.
- `script.js`: enlaces de WhatsApp, Facebook y formulario.
