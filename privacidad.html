Aviso de privacidad

Registro y recepción de perfiles cerrados.

Este aviso describe los datos tratados por el sitio actual y separa claramente los datos previstos para una futura apertura del Certificado de regalo en efectivo. La futura lista no autoriza su recopilación anticipada.

1. Responsable y contacto

SoftOhm Systems LLC, bajo el nombre comercial Saldo Express Nicaragua, decide las finalidades del tratamiento descrito en este aviso. Para privacidad, consultas o reclamaciones escribe a info@softohmsystems.com. Antes de abrir el registro se publicará cualquier información adicional del responsable que resulte legalmente obligatoria.

2. Datos tratados actualmente

  • Navegación: la infraestructura recibe información técnica necesaria para entregar y proteger el sitio, como dirección IP, navegador, fecha, hora y ruta solicitada.
  • Calculadoras: los montos se procesan en tu navegador y el código no los envía al servidor. La preferencia de tema se guarda localmente en tu dispositivo.
  • Accesos existentes al portal: se procesan correo, nombre de cuenta, contraseña protegida mediante hash, verificación de correo, sesiones y registros de seguridad. Las sesiones pueden incluir IP y navegador.
  • Consultas voluntarias: si escribes por correo o mensajería, recibimos los datos de contacto y el contenido que decidas enviar para responderte.

La home no carga scripts de analítica ni publicidad. No envíes cédula, fotografías de documentos, contraseñas, códigos, PIN ni claves bancarias por los canales de contacto.

3. Datos previstos para una futura apertura

Si el producto llega a habilitarse, una cuenta requeriría correo y contraseña. Al crear cada ticket se registrarían el nombre del familiar o beneficiario designado en Nicaragua, banco, número de cuenta, moneda, monto, modalidad, estimaciones, cotizaciones, vigencia, estado e historial de gestión. También se conservarían la versión de las condiciones aceptadas y la fecha de aceptación. La conversación del ticket conservaría el texto de cada comentario, su autor, función y fecha.

Quien proporcione datos de un familiar o beneficiario deberá informarle sobre este aviso y contar con autorización suficiente para entregarlos. Sus datos solo deberán utilizarse para revisar y, si en el futuro se habilita el producto, revisar el ticket y gestionar el certificado solicitado a su favor. El número de cuenta solo debe mostrarse al titular del ticket y al personal autorizado que atienda la solicitud.

El formulario previsto no solicita número de cédula ni fotografías de documentos, pero esto no significa que el proceso sustituya cualquier verificación legalmente exigible. Antes de abrir el registro se confirmarán los requisitos, se indicará qué campos son obligatorios y se explicará la consecuencia de no proporcionarlos.

4. Finalidades y uso

Los datos actuales se utilizan para servir y proteger la página, administrar accesos existentes y responder consultas. En una apertura futura se usarían, según corresponda, para verificar el correo, revisar el perfil, prevenir uso indebido, gestionar solicitudes, permitir la conversación entre cliente y administrador, emitir cotizaciones, mantener un historial y atender reclamaciones. Las decisiones manuales de activación, corrección, suspensión y cierre registrarían el estado, motivo, fecha y resultado del aviso enviado al correo del usuario.

Los datos no deben utilizarse para finalidades incompatibles con las informadas. Cuando una finalidad requiera consentimiento, este tendrá que solicitarse de forma separada, clara y revocable para el futuro.

5. Acceso, proveedores y transferencias

Solo debe acceder el personal autorizado conforme a sus funciones. Los proveedores de alojamiento, seguridad, almacenamiento y correo transaccional pueden procesar la información necesaria para prestar sus servicios. Esto puede implicar tratamiento fuera de Nicaragua.

Antes de habilitar nuevos tratamientos se revisarán las obligaciones y garantías aplicables a proveedores y transferencias internacionales. Solo se comunicarán datos a autoridades cuando exista un fundamento legal. Abrir enlaces externos o escribir por mensajería implica usar un servicio con sus propias prácticas de privacidad.

6. Conservación y eliminación

Los datos deben conservarse únicamente durante el tiempo necesario para la finalidad informada, la seguridad, reclamaciones y obligaciones legales o contractuales aplicables. Cerrar o suspender una cuenta no elimina automáticamente todos los registros, pero tampoco permite conservarlos indefinidamente.

Actualmente no existe un botón automático para borrar una cuenta. Las solicitudes se reciben por el correo de privacidad. Cuando proceda, los datos se eliminarán, anonimizarán o bloquearán; si existe un deber de conservación, se limitará su uso y se explicará el motivo. Las copias de respaldo seguirán su ciclo de eliminación correspondiente.

Antes de admitir clientes se establecerá y validará un calendario de conservación por categoría. No se promete borrado instantáneo ni un plazo único para todos los datos.

7. Tus derechos

Puedes solicitar información sobre tus datos, acceso, rectificación, actualización, modificación, supresión, bloqueo o cancelación, y ejercer los demás derechos que correspondan, escribiendo a info@softohmsystems.com. Indica el correo relacionado y la solicitud concreta; no adjuntes documentos de identidad de forma espontánea.

La relación con los datos se comprobará de manera proporcional. La solicitud se atenderá gratuitamente y dentro del plazo legalmente aplicable. Si no procede total o parcialmente, se comunicará el motivo y las opciones disponibles.

8. Seguridad y cambios

El portal utiliza conexiones cifradas, controles de acceso y contraseñas mediante hash. Se aplican medidas razonables para proteger integridad, confidencialidad y disponibilidad, aunque ningún sistema garantiza seguridad absoluta. No compartas claves ni códigos de recuperación.

Los cambios de este aviso se publicarán con su fecha. Antes de abrir el registro se completarán el calendario de conservación, los avisos de cada formulario y las aceptaciones que correspondan.

Referencia oficial

Este aviso se revisó tomando como referencia la Ley N.º 787, Protección de Datos Personales. La publicación del aviso no sustituye el registro, autorización o revisión operativa que pudiera corresponder antes de recopilar nuevos datos.
